## Requisitos

- Windows 10/11 con WebView2.
- Node 20+ y pnpm.
- Rust estable con el toolchain MSVC (y las Build Tools de Visual Studio).

## Comandos

```bash
pnpm install          # también copia hls.js y las fuentes de los temas (scripts/vendor.mjs)
pnpm tauri dev        # app con recarga en caliente
pnpm tauri build      # instalador NSIS en target/release/bundle/nsis
cd src-tauri && cargo test --lib
```

<Warning>
**Espacio en disco:** la carpeta `target` de Rust ocupa varios GB. Si la unidad del proyecto va justa, compila en
otra: `set CARGO_TARGET_DIR=D:\build\ejgames-target` (o `$env:CARGO_TARGET_DIR=…` en PowerShell).
</Warning>

## Variables útiles

| Variable | Efecto |
|---|---|
| `EJGAMES_DATA_DIR` | Guarda los datos en otra carpeta y funciona como instancia aparte, aunque la instalada esté abierta (pruebas). |
| `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9222` | Depurar la UI y los temas con DevTools (`scripts/cdp.mjs`). |
| `RUST_LOG=ejgames_lib=debug` | Logs detallados del núcleo. |
| `EJGAMES_INSTALL_VERB=open` | (Solo en desarrollo) Abre el instalador de un repack sin pedir administrador, para probar. |
| `EJGAMES_UPDATE_REPO=dueño/repo` | (Solo en desarrollo) Busca actualizaciones en otro repositorio. |

## Publicar una versión

<Steps>
  <Step title="Apunta los cambios">
    Añade la sección `## <versión>` a `CHANGELOG.md`: sus notas son las de la release.
  </Step>
  <Step title="Compila">
    `pnpm release patch` (o `minor`, `major`, `x.y.z`) sube la versión en `package.json`, `tauri.conf.json`,
    `Cargo.toml` y `Cargo.lock`, compila el NSIS y después el instalador propio (`installer-app/`), que lo lleva
    dentro. Deja `installer/ejGames_<versión>_Setup.exe` y nunca pisa uno anterior.
  </Step>
  <Step title="Publica">
    `pnpm publish-release` crea la release `v<versión>` en GitHub con ese instalador. Las copias instaladas la
    ofrecen al abrirse. Necesita el GitHub CLI con sesión iniciada (`gh auth login`).
  </Step>
</Steps>

El instalador propio es una app de Tauri aparte: pinta su ventana y ejecuta en silencio el NSIS de Tauri, que va
incrustado. Cuando lo abre el actualizador con `/P /R /UPDATE`, actualiza sin preguntar y vuelve a abrir ejGames.
Si al PC le falta WebView2, abre el NSIS tal cual, con los mismos argumentos.
