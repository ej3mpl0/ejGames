## The folder

Each theme is a folder inside:

```
%APPDATA%\ejGames\themes\
```

Paste that path into **Win + R** or the Explorer address bar. You can also get there
from ejGames: **Settings → Appearance → Themes folder**. (If you use the portable
version, it is the `data\themes` folder next to `ejgames.exe`.)

Create a folder inside it called `ejemplo`. By the end of the guide it will look like this:

```
ejemplo/
  theme.json    the manifest: name, options, colors…
  index.html    the page
  style.css
  main.js
```

<Warning>
**Watch out on Windows:** if extensions are hidden, it is easy to end up with a
`theme.json.txt`. Turn them on in Explorer (View → Show → File name extensions)
and save the files as UTF-8.
</Warning>

In a hurry to see it work? Copy the four files from [`examples/ejemplo-tema/`](https://github.com/ej3mpl0/ejGames/tree/main/examples/ejemplo-tema) into
that folder and keep reading to understand each part.

## Make it show up in the gallery, and turn it on

Open **Settings** (**Ctrl + ,**) → **Appearance**. The gallery reads the themes
folder again every time you enter, so your theme appears without restarting
ejGames. Press the **Mi primer tema** card. Your themes are marked as yours.
The chosen theme is saved in your profile.

## Developer mode and reloads

On that same screen, in the **Make it yours** block, turn on **Developer mode**.
With it:

- the theme **reloads itself every time you save** any of its files,
  including `theme.json` (name, options, colors, sounds);
- your theme's JavaScript errors show up as notices ("Theme: …").

**F5** reloads the theme by hand at any time (there is also a **Reload theme**
button). If you save a `theme.json` with an error, the theme keeps the previous
version until you fix it.

## If something goes wrong

- **An error in your JavaScript** leaves the theme blank or half drawn. With
  developer mode you will see the notice with the error. Fix it, save, and that is it.
- **If the theme hangs** (an infinite loop, for example), after a few seconds
  ejGames loads the house theme, Moneda, and tells you: “The theme «Mi primer tema»
  isn't responding. The house theme was loaded.” Fix the problem and choose your
  theme again in Appearance.
- **Safe mode:** hold **Shift** while opening ejGames and it will start with
  Moneda, in case yours will not even let you reach settings.
