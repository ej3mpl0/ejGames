This guide is for you if you know some HTML, CSS and JavaScript and want to build a
theme **from scratch**, without starting from a built-in one. Together we will build
a theme that is small but complete:

- a grid of your games' covers,
- used with mouse, keyboard or controller,
- with a page for each game (description, Play/Install, favorite),
- with options anyone can change in **Settings → Appearance** without touching code,
- and that adapts to **Big Picture**.

The finished result is in [`examples/ejemplo-tema/`](https://github.com/ej3mpl0/ejGames/tree/main/examples/ejemplo-tema): four files you can copy as they are. This guide is practical. To see **everything** the SDK offers, use the [reference](/referencia/sdk).

<Note>
The example writes its interface in Spanish. That Spanish text is the translation key: English, and the other languages, come from a dictionary, with no code changes. See [Languages](/referencia/idiomas).
</Note>

## Before you start: what a theme is

A theme is an **ordinary web page** that ejGames opens fullscreen. It runs in a
closed box (an isolated *iframe*): no internet, and no access to the disk. Everything
it needs, it asks ejGames for through an object that appears on your page on its own,
**`window.ejg`** (the SDK): the list of games, notices when something changes,
launching a game, opening settings…

The launcher's own screens (settings, search, the game editor, the quick menu,
profiles) are drawn by ejGames **on top of** your theme. You only take care of
showing the library your way.
