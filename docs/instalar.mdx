## Install

<Steps>
  <Step title="Download the installer">
    Get `ejGames_<version>_Setup.exe` from the [latest GitHub release](https://github.com/ej3mpl0/ejGames/releases/latest).
  </Step>
  <Step title="Open it">
    Choose the folder (by default `%LOCALAPPDATA%\ejGames`), whether you want a desktop shortcut, and whether it
    should open when it finishes. It does not ask for administrator permission.
  </Step>
  <Step title="First launch">
    A four-step wizard asks for your profile, your theme, which folders hold your games, and
    the downloads folder. All of it can be changed later in **Settings**.
  </Step>
</Steps>

If you already had ejGames, the same installer detects it and offers **Update**. Your library, your hours and your
settings stay as they are.

## Requirements

- Windows 10 or 11, 64-bit.
- WebView2, which already ships with Windows 11 and with up-to-date Windows 10. If it is missing, the installer opens
  the classic installer, which downloads it.

## Updates

On launch, ejGames checks GitHub for a newer version. If there is one, it shows what is new and, with one button:

1. downloads it and checks that the installer is the one that was published (SHA-256),
2. closes ejGames and installs it without touching your data,
3. and opens it again.

You can skip a version or leave it for later. **Settings → System → Updates** turns off the check on launch, and
**Search now** is there too.

<Note>
Automatic updates arrived in 0.3.0. If you have an older version, install 0.3.0 by hand once.
</Note>

## Where your data lives

Everything is in `%APPDATA%\ejGames\`:

| What | Where |
|---|---|
| Library, hours, profiles and collections | `library.db` (SQLite) |
| Settings | `settings.json` |
| Log | `logs\ejgames.log` |
| Game art | `cache\media` |
| Trailers | `cache\trailers` (with a configurable size limit) |
| Your themes | `themes\` |

**Portable:** with a `portable.txt` file next to `ejgames.exe`, everything goes to `.\data` in that same folder.

## If something goes wrong

- **Safe mode:** hold **Shift** while opening ejGames to start with the house theme, Moneda.
- **Log:** `%APPDATA%\ejGames\logs\ejgames.log` records what happened.
- **Uninstall:** **Windows Settings → Apps → Installed apps → ejGames**. Your data
  stays in `%APPDATA%\ejGames` in case you come back; delete that folder if you do not.
