Los emuladores instalados (juegos con `source: "emulator"`) y los juegos de consola (los que tienen `platform`: ROMs
propias, homebrew y lo bajado de los catálogos) no son de la biblioteca de PC: van en **Homebrew**, una vista aparte
junto a la biblioteca. Desde la 1.4.0, `visible()` del kit ya los deja fuera:

```js
import { visible, roms, software, romsBySystem } from "/_sdk/kit/library.js";

visible(ejg.library.all);                  // solo los juegos de PC
visible(ejg.library.all, { roms: true });  // también los de consola
roms(ejg.library.all);                     // los de consola, por nombre
romsBySystem(ejg.library.all);             // [{ id, name, games }] por sistema
software(ejg.library.all);                 // los emuladores
```

## La forma rápida: la vista del kit

`/_sdk/kit/homebrew.js` trae la vista entera, con mando, como una tienda: buscador y una pestaña por consola arriba;
lo que se está bajando; tus juegos de consola; filas de populares, novedades y una por consola de los catálogos (las
de cada consola se piden al acercarse); la ficha de cada juego con **Descargar**, su progreso, **Jugar** y **Borrar**;
y tus emuladores (instalados, configurados a mano y los que faltan). Se repinta sola cuando cambia la biblioteca, empieza
una partida o avanza una descarga.

```html
<link rel="stylesheet" href="/_sdk/kit/homebrew.css" />
```

```js
import { createHomebrewView } from "/_sdk/kit/homebrew.js";

const hb = createHomebrewView({
  ejg,
  root: document.getElementById("homebrew"), // un contenedor visible (el scroll es suyo o de un padre)
  focus,                                     // tu createFocus()
  layout: "xbox",                            // steam | ps5 | xbox | switch | cinema | retro
  onExit: volverAInicio,                     // «Atrás»
  onChange: () => pistas.set(hb.hints()),
  onGame: (g) => abrirFicha(g.id),           // sin él, A juega directamente
});

// Antes que tu propia navegación:
bindNav(focus, {
  back: () => hb.nav("back") || miAtras(), // cierra la ficha, vuelve al inicio de Homebrew o llama a onExit
  lb: () => hb.nav("lb"),   // consola anterior / siguiente
  rb: () => hb.nav("rb"),
  x: () => hb.nav("x"),     // borrar el juego enfocado (el diálogo del host lo confirma)
  y: () => hb.nav("y"),     // la tienda de emuladores
});

hb.destroy(); // al salir
```

`onExit` se llama con **Atrás** en el inicio de la vista: devuelve `false` si ahí no hay nada que hacer. Las tarjetas de
tus juegos llevan `data-game-id`, así que tus atajos de siempre (favorito, propiedades…) siguen funcionando sobre ellas.

### El aspecto

La maqueta (`layout`) cambia las formas: carátulas cuadradas en `ps5`, `xbox` y `switch`, pósteres en `steam` y
`cinema`, bordes de píxel y foco en negativo en `retro`. Los colores son los de tu tema, con estas variables en
`.hb-view`:

| Variable | Para qué |
| --- | --- |
| `--hb-fg`, `--hb-muted` | texto y texto secundario |
| `--hb-accent`, `--hb-accent-fg` | acento (chip elegido, botones) y el texto encima |
| `--hb-surface`, `--hb-surface-2`, `--hb-line` | tarjetas, tarjetas enfocadas y bordes |
| `--hb-radius`, `--hb-focus` | esquinas y anillo de foco (`box-shadow`) |
| `--hb-hero` | fondo de la cabecera |
| `--hb-font`, `--hb-title-font` | fuentes del texto y de los títulos |
| `--hb-cover`, `--hb-card` | proporción y ancho de las carátulas de tus juegos |
| `--hb-item` | ancho de las tarjetas de los catálogos (16:9) |
| `--hb-sheet`, `--hb-input`, `--hb-input-on` | fondo de la ficha y del buscador (normal y enfocado) |
| `--hb-warn`, `--hb-ok` | avisos (falta emulador) y actualizaciones / en juego |

## Los catálogos

```js
const { sources } = await ejg.catalogs.state();
// [{ id, name, hasSearch, platforms: [{ id: "ps1", system: "psx", name: "PlayStation" }] }]
await ejg.catalogs.browse({ source: "romshq", mode: "popular" });          // también "newest", "platform" y "search"
await ejg.catalogs.browse({ source: "romshq", mode: "platform", platform: "ps2", page: 2 });
await ejg.catalogs.search("zelda", { platforms: ["switch"] });          // en todas las fuentes a la vez
const ficha = await ejg.catalogs.detail(entry.sourceId, entry.id);      // + links y screenshots
await ejg.catalogs.download(entry.sourceId, entry.id, ficha.links[0].url);
ejg.catalogs.jobs;                                // { "<fuente>|<id>": { name, phase, received, total, gameId } }
ejg.catalogs.onJobs((jobs) => …);                 // como mucho una vez por segundo
ejg.catalogs.cancel("romshq|/game/…");
```

Cada entrada trae `title`, `coverUrl` (servida por ejGames), `platform` (la del catálogo) y `system` (la de
`game.platform`), `size`, `region`, `installedGameId` si ya está en la biblioteca y `emulator` (con qué se
jugaría). `download` solo acepta un enlace de la ficha: los directos van a la cola (se bajan, se descomprimen y quedan
en la biblioteca: `"queued"`), una web de descargas se abre en el navegador (`"opened"`) y un torrent abre la ventana
de catálogos (`"catalogs"`). Para borrar un juego de consola, `ejg.game.uninstall(id)`: el host lo confirma y manda
sus archivos a la papelera.

## Los emuladores de la tienda

```js
const list = await ejg.emulators.list();
// [{ id, name, blurb, systems, platforms, installed, version, latest, update, gameId }]
```

`platforms` son los mismos ids que `game.platform` (`switch`, `ps2`, `psx`…) y `systems` sus nombres; `gameId` es su
entrada en la biblioteca (para `ejg.game.launch`) si está instalado, y `update` dice si hay una versión nueva. La
primera llamada de la sesión pregunta las versiones a sus webs. Para instalarlos o actualizarlos, la tienda del host:
`ejg.ui.open("software")`. Importar ROMs: `ejg.ui.open("rom-import")`.
