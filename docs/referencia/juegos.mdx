```js
const d = await ejg.game.details(id)   // + description, screenshots[], trailers[], recentSessions[]
await ejg.game.launch(id)
ejg.game.favorite(id)                  // alterna (o pasa true/false)
ejg.game.hide(id, true)
ejg.game.rate(id, 80)
ejg.game.edit(id)                      // abre el editor del host
ejg.game.openFolder(id)
ejg.game.uninstall(id)                 // abre el diálogo «Desinstalar» del host
ejg.game.isRunning(id)
ejg.game.onState(({ gameId, state }) => …)   // "launching" | "running" | "stopped"
```

`description` es texto con un marcado mínimo (`## título`, `- viñeta`,
párrafos separados por línea en blanco). `description()` del kit lo convierte en
nodos DOM seguros.

Los tráilers (`d.trailers[i].url`) son HLS (`.m3u8`): usa `attachStream()` del kit,
que usa HLS nativo o hls.js según haga falta.

## Desinstalar

`ejg.game.uninstall(id)` no desinstala nada por sí solo: abre un diálogo del host que
explica qué va a pasar y pide confirmación.

- **Si el juego tiene desinstalador**, se abre (el de su entrada en «Aplicaciones
  instaladas» de Windows, o un `unins000.exe` / `uninstall.exe` de su carpeta). Cuando el
  juego desaparece del disco, sale de la biblioteca.
- **Si no tiene nada**, su carpeta va a la papelera de reciclaje. Nunca se borra una carpeta
  de la biblioteca, de descargas o del sistema, ni una que tenga dentro otros juegos.

Sirve para cualquier juego que siga en su sitio. Para saber si enseñar la opción, usa
`canUninstall(juego)` del kit (`/_sdk/kit/library.js`).

Los emuladores instalados desde **Tienda → Software** están en `library.all` con `source: "emulator"`: no son juegos.
`isSoftware(juego)` los distingue, `visible()` los deja fuera y `software(library.all)` los da para su apartado.

Los juegos de consola (`source: "rom"` o `"homebrew"`) llevan `platform` (`"switch"`, `"vita"`, `"3ds"`, `"ps2"`…),
`emulator` (con qué se abren; `""` si no hay ninguno) y `rom` (lo leído del archivo: `titleId`, `version`, `region`,
`serial` y `extras`, sus actualizaciones y DLC). Del kit:

```js
import { isRom, romsBySystem, systemName, romParts } from "/_sdk/kit/library.js"
import { emulatorNote } from "/_sdk/kit/emulator.js"

romsBySystem(ejg.library.all)   // [{ id: "switch", name: "Nintendo Switch", games: [...] }, ...]
ficha.append(emulatorNote(game)) // «Requiere emulador: Eden» + TitleID, versión, región, DLC; nada en los de PC
ejg.ui.open("homebrew", { system: "vita" })  // Homebrew (Tienda → Software)
ejg.ui.open("rom-import")                     // Importar ROMs
```

<Note>
Al desinstalar, el juego sale de la biblioteca junto con sus horas y su actividad.
</Note>
