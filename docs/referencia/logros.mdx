---
title: "Achievements"
description: "ejg.game.achievements: list, icons and rarity."
icon: "trophy"
---

```js
const list = await ejg.game.achievements(id)
// { total, unlocked, items: [{ apiName, name, description, icon, iconGray,
//                              hidden, globalPct, unlockedAt }] }
```

They come from the game's emulator files (and, if you have Steam installed, from
its local stats). The first time can take a moment, because it downloads the
Steam schema. After that it is cached for a week. To paint a summary without
waiting, use `game.achievements` from the library.

- `items` follows the game's order. Without `unlockedAt`, the achievement is locked.
- `icon` and `iconGray` are served through `ejg-media`, so they load in the theme
  with no network.
- `globalPct` is the percentage of Steam players who have it. Use it to mark rarity.
- A hidden achievement that is still locked arrives named `Logro oculto`, with
  no icon and no description. That name is a normal string, so a dictionary entry translates it.
