---
title: "Profile"
description: "ejg.profiles: the active local profile (name, avatar and color), switching profiles and editing it."
icon: "user"
---

Each local profile has its name, its avatar (or its initial on its color), its theme and its hours. Everything is stored **on the
PC**: there are no accounts and no server. With that you paint your theme's avatar and the menu on your picture.

```js
ejg.profiles.current();                // the local profile: { id, name, avatar, color, themeId }
ejg.profiles.me;                       // the same, short, with no call: { id, name, avatarUrl, color }
ejg.profiles.onChange((me) => …);      // the name or the avatar changed
ejg.profiles.switch();                 // the host's profile picker
ejg.profiles.edit();                   // Settings → Profile (name, avatar, PIN…)
```

Changing profile also sends the `profile` event:

```js
ejg.on("profile", (p) => pintarAvatar(p));
```

<Note>
Until 1.3 there was a Steam-style profile page (frames, showcases, level and badges). Since 1.4.0 it no longer
exists: `ejg.profiles.view()`, `open()` and `badges()` were removed, `/_sdk/kit/profile.js` too, and
`features.profile` in `theme.json` does nothing.
</Note>
