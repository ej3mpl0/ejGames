---
title: "Perfil"
description: "ejg.profiles: el perfil local activo (nombre, avatar y color), cambiar de perfil y editarlo."
icon: "user"
---

Cada perfil local tiene su nombre, su avatar (o su inicial sobre su color), su tema y sus horas. Todo se guarda **en el
PC**: no hay cuentas ni servidor. Con eso pintas el avatar de tu tema y el menú de tu foto.

```js
ejg.profiles.current();                // el perfil local: { id, name, avatar, color, themeId }
ejg.profiles.me;                       // lo mismo en corto, sin llamada: { id, name, avatarUrl, color }
ejg.profiles.onChange((me) => …);      // cambió el nombre o el avatar
ejg.profiles.switch();                 // el selector de perfiles del host
ejg.profiles.edit();                   // Ajustes → Perfil (nombre, avatar, PIN…)
```

Al cambiar el perfil también llega el evento `profile`:

```js
ejg.on("profile", (p) => pintarAvatar(p));
```

<Note>
Hasta la 1.3 había una página de perfil al estilo Steam (marcos, vitrinas, nivel e insignias). Desde la 1.4.0 ya no
existe: `ejg.profiles.view()`, `open()` y `badges()` se quitaron, `/_sdk/kit/profile.js` también, y
`features.profile` en `theme.json` ya no hace nada.
</Note>
