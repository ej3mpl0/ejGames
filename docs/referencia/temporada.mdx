En sus fechas, ejGames se viste para la ocasión. El primero es **ejGames Scream** (Halloween, del 26 de octubre
al 2 de noviembre). El usuario lo elige en **Ajustes → Apariencia → Modo Halloween en la tienda**: *En sus
fechas*, *Siempre* o *Nunca*. El host decide si hay un evento activo y se lo manda a tu tema.

## Lo que hace el SDK sin que hagas nada

Mientras dura el evento:

- Pone `data-season="halloween"` en `<html>` y las variables `--ejg-season-accent` (naranja calabaza),
  `--ejg-season-green`, `--ejg-season-violet`, `--ejg-season-bg`, `--ejg-season-panel` y `--ejg-season-text`.
- Cambia tus opciones de color `accent`, `bg`, `panel` y `play`, activa `dark` y pone su fondo en la
  opción `wallpaper` de tipo imagen (`ejg.settings` ya los trae). Al acabar vuelven las del usuario.
- Carga una capa de ambiente encima de todo (`#ejg-season`): niebla a ras de suelo, ascuas y algún murciélago.
  No recibe clics y se queda quieta con «reducir movimiento».

Para lo que no sale de tus opciones (colores fijos, logos, decoración), usa el selector en tu CSS:

```css
:root[data-season="halloween"] .topbar {
  background: linear-gradient(90deg, #1d1330, #120c1c);
  box-shadow: inset 0 -1px 0 var(--ejg-season-accent);
}
```

## En JavaScript

| | |
|---|---|
| `ejg.season.id` | `"halloween"` o `null` |
| `ejg.season.event` | el evento: `name`, `dates`, `banner`, `video`, `wallpaper`, `wallpaperVideo`, `wallpaperAlt`, `palette`, `genre`, `title`, `subtitle` |
| `ejg.season.mode` | el ajuste del usuario: `"auto"`, `"on"` u `"off"` |
| `ejg.season.onChange(fn)` | empieza o acaba un evento, o cambia el ajuste (`fn({ mode, season })`) |

Al cambiar, también llega el evento `settings` (con la paleta ya aplicada o quitada).

## La tienda: banner y selección

`/_sdk/kit/events.js` trae las piezas para la portada de tu tienda:

```js
import { seasonOf, seasonBanner, seasonPicks } from "/_sdk/kit/events.js";

const ev = seasonOf(ejg);   // null sin evento
if (ev) {
  front.prepend(seasonBanner(ev));   // el banner animado en bucle (2000×297)
  const { items, loading } = seasonPicks(ejg, ev, home.sections, repaint);
  // items: los de su género (Terror), primero los populares; con `loading`, repaint() avisa al llegar el resto
  front.append(miFila(ev.title, items, () => openCatalog({ genres: [ev.genre] })));
}
ejg.season.onChange(repaint);
```

El arte está en `/_sdk/events/<id>/`: `banner.webp` y `banner.mp4`, `wallpaper-street.jpg` (y su versión
animada `.mp4`) y `wallpaper-graveyard.jpg`. Los seis temas de serie lo usan; mira el de Steam
(`themes/steam/store.js`, `eventFront`) como ejemplo.
